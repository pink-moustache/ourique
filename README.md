# Ourique — Campo de Ourique, Lisboa

Apresentação editorial do projeto imobiliário Ourique, localizado no coração de Campo de Ourique, Lisboa.

## Stack

- HTML/CSS/JS vanilla — sem dependências de build
- [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond) + [Tenor Sans](https://fonts.google.com/specimen/Tenor+Sans) via Google Fonts
- [Leaflet.js](https://leafletjs.com/) para mapa interativo
- Deploy automático via Netlify
